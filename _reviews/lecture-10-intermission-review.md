# Review: lecture-10-intermission.qmd

**Reviewed:** 2026-07-07
**Scope:** Pedagogy, model formulation, math notation, code, content robustness, writing polish

## Summary

A genuinely useful exam-prep deck: the three-part mock exam mirrors the real format, the points sum exactly to 60 (30 + 15 + 15), matching the stated "1 point ≈ 1 minute" rule, and the solutions-profile / typst-pagebreak setup cleanly serves both slide and printed-exam use. The coappearance matrix in 2.b is correct (verified by hand). The main weaknesses are inside the sample solutions: the debugging exercise 3.a contains more discrepancies than the seven the solution lists, Part I's solution silently switches from "units" to "truckloads", and several solution texts (1.d, 2.e, 3.a items 1 and 3) are muddled enough that a student cross-checking against them would be confused.

## 1. High-impact teaching improvements

- **3.a has nine discrepancies, not seven** (lines ~420–450). Beyond the seven listed errors, the constraints use `available[i]` (line ~442) and `requested[j]` (line ~446) while the preamble defines `availablePanels`/`requestedPanels` (lines ~426–427) — exactly the kind of naming mismatch the "Programming Tips" box (line ~403) tells students to hunt for. A careful student will find 9 candidate errors and lose time deciding which 7 "count". Either rename the constraint data to `availablePanels[i]`/`requestedPanels[j]` so exactly seven errors remain, or extend the callout to state explicitly that `available`, `requested`, and `travelCosts` are also correctly loaded.
- **Units vs. truckloads contradiction in Part I** (lines ~72–78). The problem statement (lines ~56–60) is entirely in *units* of ice cream ("agreed number of units", "capacity for a number of units", "each unit consumes a different amount of space"), yet the solution defines $b_{i,j}$ as "truckloads of sort $i$ demanded" and $X_{i,j}$ as "number of shipped truckloads from $i$ to $j$". With per-unit space consumption $u_i$, the capacity constraint $\sum u_i X_{i,j} \le k$ (line ~135) only makes sense if $X$ counts units. Also, "from $i$ to $j$" misreads $i$ as an origin — it indexes ice cream sorts. Rewrite as "$X_{i,j}$: units of sort $i$ shipped to supermarket $j$".
- **1.d sample answer starts with a self-contradiction** (line ~165): the question is "Is the model a linear problem *with binary variables*?" and the solution answers "Yes, the model formulation is a linear problem but it does not have binary variables". As a model answer for graders and students, it should read "It is a linear problem, but it has continuous rather than binary variables, so no." While here, address the elephant in the room: units of ice cream are discrete, so a sentence on why the continuous relaxation is acceptable (or a note that integer $X$ would also earn full marks) would preempt the most likely student objection.
- **Show the point budget explicitly.** The "Exam's structure" slide (lines ~22–26) states the 1-point-≈-1-minute rule; adding "this mock exam is 60 points ≈ 60 minutes" (and whether that matches the real exam length) turns the rule into a concrete time-management plan, which the Key Takeaways slide (line ~563) says is crucial.

## 2. Model & notation issues

- **$Y_{i,j}$'s binary domain is never declared** (line ~192): the solution says "1, if demand $b_{i,j}$ is unfulfilled (Variable)" but never writes $Y_{i,j} \in \{0,1\}$. Since 1.c explicitly asks for "variable ranges" and the criteria the course itself teaches demand explicit domains, the model answer should set the example. Same for 1.f: "$Z$ as integer variable" (line ~232) should be $Z \in \mathbb{Z}_{\ge 0}$ — without non-negativity, negative $Z$ would be allowed and (with the max objective and $r > 0$… actually it would *reduce* capacity while earning money only if $r < 0$; still, state it).
- **1.e constraint edge case worth a sentence** (line ~203): $b_{i,j} - X_{i,j} \le Y_{i,j} b_{i,j}$ forces $Y = 1$ only for *partially* unfulfilled demand and relies on the $-p_i Y_{i,j}$ term (with $p_i \ge 0$) to push $Y$ to 0 otherwise. A one-line "why does $Y$ stay 0 when demand is met?" note would model the reasoning students must reproduce. Note also the problem says "pay a one-time fee for the ice-cream sort", yet the fee is charged per sort *and* supermarket ($\sum_j p_i Y_{i,j}$) — consistent with "each demand of a supermarket", but the two sentences in the problem statement (line ~179) pull in different directions; tighten the story.
- **"u.t.c" is used nowhere else in the course** (line ~131): every other lecture (01, 06, 08, 09, 11, 12) writes "subject to". In an exam-prep document that students will copy onto their cheat sheet, use the course-standard "subject to" (or "s.t.").
- **1.f labels a modified constraint "New constraint"** (line ~240): the capacity constraint $\sum u_i X_{i,j} \le k + 2k Z$ replaces the one from 1.c. Since the question explicitly distinguishes "additional or modified" elements, label it "Modified constraint" — that distinction is worth points in the real exam.
- **3.b notation clashes with course conventions** (line ~480): the LaTeX uses `*` ($7 * U_{gm} * T_m$) while the rest of the deck uses $\times$, and $U_{gm}$ drops the comma used in $X_{i,j}$ elsewhere. Also "the following equations are given" describes a single inequality — say "the following constraint". Finally, if capital letters denote variables (course convention), $U_{gm} T_m$ is a product of two variables, i.e. nonlinear — fine for a syntax exercise, but given 3.d asks about linear vs. nonlinear, consider making $T_m$ lowercase (a parameter) to avoid a sharp student asking why the exam contains a nonlinear constraint.
- **2.c overstatement** (line ~337): "If the problem is linear, the global optimum is the same as the local optimum" — better: "in a linear problem, every local optimum is also a global optimum" (there can be multiple optima, and "the local optimum" presumes uniqueness).
- **2.e Big-M explanation is muddled** (line ~383): "it effectively forces the binary variable to 'turn on' that constraint" inverts the mechanism — the large M *relaxes* (deactivates) a constraint when the binary variable takes one value and lets it bind for the other. As a model answer, rewrite along the lines of: "adding $M(1 - Y)$ to one side makes the constraint non-binding when $Y = 0$ and active when $Y = 1$."

## 3. Content & robustness

- **3.a solution item 1 doesn't match the code** (line ~456): the solution says the model should be called `transportModel`, but the macros use `transport_model` (lines ~433–449). The fix description itself contains an error — in a debugging exercise, that undermines trust. Say "`transport` and `transport_model` are inconsistent; use one name".
- **3.a solution item 3 has a stray token** (line ~458): "'.>= 0'" — the leading dot looks like a broadcast typo. Write: "the variable should be continuous and non-negative: `X[i,j] >= 0` instead of `Bin`".
- **Unnecessary environment activation** (line ~15): `activate_environment.qmd` runs `Pkg.activate` but this lecture executes no Julia code — all code blocks are plain ```` ```julia ```` listings. Dropping the include removes a Julia startup dependency from a deck you may want to open quickly in the exam-prep session.
- **Semester-bound evaluation link** (lines ~48–50): the EvaSys URL with password `NL6UD` and the matching QR code will be stale next semester — worth a `<!-- update each term -->` comment.
- **"Lecture X" title** (line ~2): consistent with the Roman-numeral convention (IX, XI, XIII), but unlike "IX" or "XIII", a lone "X" reads as a placeholder. Consider "Lecture X (Intermission)" or spelling it in the subtitle to avoid the double take.

## 4. Pedagogy & polish

- **Typos** (line ~573): "todays lecture" → "today's lecture"; (line ~575) "tuorial" → "tutorial".
- **"Note, that"** — the comma is a Germanism; "Note that…" (lines ~60, ~184, ~224).
- **"maximally deliver the agreed number of units"** (line ~58) — another Germanism ("maximal"); say "deliver at most the agreed number of units", which also states the constraint more precisely.
- **"Exam's structure"** (line ~22) → "Exam structure".
- **"transportation costs per truckload are totally negligible"** (line ~58): "totally" is informal for exam text; "negligible" alone suffices. Also, mentioning "truckload" here while everything else is per-unit feeds the units/truckloads confusion flagged above.
- **Double space** (line ~269): "could for example  include".
- **2.a asks for 2–3 sentences but the model answer is two paragraphs plus bullets** (lines ~265–273): fine as enriched solution material, but mark the bullets as "background beyond the expected answer" so students calibrate the expected response length correctly.
